Personal Portfolio Website

A simple, responsive portfolio website built with HTML, CSS and a little vanilla JavaScript — no frameworks, no build tools.

Files
- index.html — page content and structure
- styles.css — all styling (including the dark theme)
- script.js — small interactive features

JavaScript features
- Dark / light theme toggle (remembers your choice)
- Nav link highlights the section you're viewing
- "Back to top" button that appears when you scroll down
- Footer year updates automatically
